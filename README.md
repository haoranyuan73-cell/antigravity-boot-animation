# 反重力开机动画 (Antigravity Boot Animation)

Antigravity 自定义开机启动动画成品与软件内嵌星门过渡页。

## 仓库内容

- **双子星单人版开场动画**（`反重力开场_Gemini单人版.mp4`）：1080p 高清开场动画，星门展开后与内置主题无缝衔接。
- **三 AI 娘同框版开场动画**（`反重力开场_三AI娘同框版.mp4`）：1080p 高清三人同框开场动画。
- **内嵌星门过渡页**（`boot-overlay.html`）：用于软件启动时的透明浮层，负责在星门框内展示当前壁纸与呼吸徽标，并在就绪后平滑放大过渡到主界面。
- **宇宙氛围音效与语音混音脚本**（`build_cosmic_audio.py`）：生成深空氛围音景并与“欢迎回来”人声混音输出立体声音轨。

## 本地预览方式

直接用浏览器打开 `boot-overlay.html`，可在地址末尾加上参数进行演示：

- 预览单人版：`?demo=1`
- 预览三人同框版：`?variant=trio&demo=1`
- 按 `Esc` 键可提前跳过播放。
